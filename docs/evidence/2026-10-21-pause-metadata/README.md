# Spotify 暂停后歌词消失

输入 main：a479eb9860647c27fdecc015e169df4c6923055b。仅修改 PlaybackState 的现有桌面快照接入，以及原有的暂停/恢复测试。

## 实机原因

用户切走、切回并暂停时，只读记录了 Spotify 的广播字段（notification-fields.txt）：07:24:26Z 的 Playing 通知为日文歌名和专辑；07:25:54Z 的 Paused 通知变成 Light source / Even if it was a small prayer。ID、歌手和 246.49 秒时长没有变化。App 因标题/专辑指纹变化开启另一歌词会话，清掉已显示的歌词，随后本地精确匹配失败。只读检查确认原有歌词版本仍在，没有删除。

修复仅在同一次已接受的 Spotify 播放记录内，且 ID、非空歌手及接近的时长都一致时，保留已接受的歌曲元数据。播放状态和位置仍更新；实际换 ID、歌手或时长仍重新接入。通知和 App 发起恢复后的完整读取共用这一处处理。没有修改 TrackIdentity、数据库、旧版本或跨歌曲匹配规则。

# Lyric Island 第二轮｜实施裁决与性能保护

2026-10-18。当前代码基线：`12df41685d615e11c211ad713e639a68f1e4a5ac`。
本文件记录本轮确定的实施边界；当前进度主源仍是 Obsidian Handoff。

## 1. 采用五场景，但保留用户喜欢的真实效果

采用交接包的五个可直接选择的场景：原版环境光、流动光场、封面写真、唱片内页、专注歌词。
不再以早期三构图 HTML 覆盖该选择。当前五套尚未完成原生实施。

- 原版环境光保持已认可的视觉和取景。不是再次“复原”一个旧错误版本。
- 经典放大/纯高斯的柔化肌理保留为封面写真的真实预设，不统一成同一个模糊曲线。
- 当前羽化完整效果与偏好保留；新场景的羽化选项不能用一个新 mask 冒充旧效果。
- 喜欢的效果在相关场景内要容易返回，不只是埋在历史备份中。
- 八套 rawID、保存偏好及选中状态不改。升级首次显示原画面；用户主动选择新场景才进入新布局。
- 新场景选择与旧渲染 ID 分开，使用有限映射，不建立任意组合的参数矩阵。
- 同一时刻只构建当前生效的主场景；场景缩略图采用固定图片或受控按需快照，不预建五套完整歌词树。

其余确定的产品方向：外置调整窗（不挤主画布）、数值可编辑、更多选项初次默认展开并保存手动状态、可关闭悬停预览、跟随封面颜色、全场景局部阅读保护、状态栏固定宽度长句慢滚（仍可省略）。歌词正文/身份/时间轴/译文分层处理。

## 2. 性能不是收尾项目，而是合入条件

禁止给出“保证不会发生 bug”的承诺，也不把编译或单元测试当原生性能证据。
保护 12df416 已有成果：纯时间广播过滤、稳定读音/播放回调、row/ruby布局缓存、隐藏播放器停止装饰、隐藏桌面/胶囊释放内容、工具窗按需创建及实际宿主测量规则。

### 更新边界

1. 动画/指针只能更新对应小组件，不向主窗、全歌词列表或全局设置广播每帧状态。
2. 不新增轮询取色、每行 Timer、隐藏场景 Timeline、每帧大图 blur/取样。
3. 配色复用封面缓存；同曲同封面不重复抓取或分析。动效关闭后仍有完整静态设计。
4. 菜单长句仅在确有溢出且该表面可显示时滚动；短句、暂停/减少动态时不启动无谓更新。
5. 外置工具关闭后遵守已有隐藏内容释放；不能保持不可见的完整歌词/预览树。
6. 新来源发现有界、可取消、去重、缓存；不整站遍历，不因换主题或开面板找词/调用模型。
7. 任何确认的性能倒退，先撤回本批独立改动，不回滚已有优化，也不关闭用户功能伪装通过。

### 原生合入门槛（NOT_RUN，不是已有结果）

- 比较固定基线与候选：同一 Mac、优化 Debug (`-O`)、相同隔离数据副本、同歌曲及播放区间、同窗口/字号/文字层/辅助窗状态。不要拿普通 Debug 对优化 Debug。
- 先预热，再采样。现有 8.003秒/0.77 CPU秒样本只对应一次 KG 49行/纯高斯；它不是所有主题的硬指标，更不能据此宣称 CPU 已降多少。
- 每批做少量成对 30–60秒观察，明显波动才复测；保留 CPU 时间/墙钟、内存稳定段、切行/操作停顿。截图/录屏不能混入用于比较的采样段。
- 第一批重点：鼠标停在歌词区、边缘来回操作、关闭窗口/辅助内容后闲置。重复打开关闭后不能持续积累订阅或内存；有缓存时先区分有界保留与持续增长。
- 新流动光场/状态栏滚动之后各自有开/关对照；不能等五场景全部接完才第一次量资源。
- 出现可重复的持续 CPU/内存上升、空闲仍渲染、切行停顿增大，阻止合入。没有真实样本就记 NOT_RUN，不用主观“很流畅”替代。
- 不新增日常遥测框架、持续全量日志或大型截图系统；优先使用现有 Mac 取样工具。

## 3. 第一批实际代码：边缘交互状态

只修改生产文件 `SpotifyLyrics/Views/MainWindow/V3WindowEdgePlaybackOverlay.swift`。

- 当前鼠标接近的边决定位置；上次退出点只作无当前锚点时的兜底。
- 被动唤出 30pt、保持 46pt；按钮及连接区域内锁住位置，沿边明显移开再重新定位。
- 保留进度线常驻、0.16秒淡出、减少动态、inactive window 跟踪、seek录音身份保护。
- 不扩大现有可点击 seek 边带，避免把扩大唤出区变成抢占歌词点击。
- 不新增计时器/显示时钟/全局publisher。只有可见性或锚点实际变化才写局部SwiftUI状态。
- 松开进度拖动后用真实指针重新判定显示；旧曲目未完成拖动不会 seek 新曲。
- 主窗、背景、歌词会话、布局缓存、辅助窗口生命周期、Xcode项目配置均未修改。

这批不包含跟随封面、外置面板、菜单滚动、新场景、TuneCore接入或完整视觉大改。它是有独立回退边界的第一步，不是以小修替代整轮交付。

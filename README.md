# Aster · Lyric

**星弦 · macOS 原生歌词伴侣**

听歌时，把画面留给封面，把注意力留给歌词。

为 Spotify 与 Apple Music 打造的 macOS 原生歌词伴侣。  
原文、译文、注音，以及属于你的歌词版本库。

> 本页介绍的是 **`main` 分支的开发中版本**。目前已发布的 [v0.1.2](https://github.com/suifracti/aster-lyric/releases/tag/v0.1.2) 仍使用旧名 SpotifyLyrics，不包含本页全部新功能。体验当前版本需要从源码构建；发布包的功能以对应 Release 说明为准。

音乐仍在 Spotify 或「音乐」App 中播放。Aster · Lyric 跟随当前歌曲，把封面、歌词、翻译和读音放在一个阅读空间里；也可以退到桌面或菜单栏，陪你做其他事情。

平时少一点界面干扰，需要时仍有完整工具：换一个歌词来源、调整一行读音、按自己的习惯重新翻译，或把修改保存为独立版本。**简洁的是听歌画面，不是功能。**

## 功能介绍

### 为不同的听歌方式，保留不同的画面

主窗口按四类场景组织，同一类中再选择具体风格。原版环境光、经典放大模糊和完整羽化都保留，不需要为了换一种布局而放弃喜欢的效果。

| 场景 | 画面的重点 | 可选风格与用途 |
| --- | --- | --- |
| **环境光** | 完整封面、专辑色彩与歌词相伴 | 原版环境光、柔光羽化、柔和光晕等风格，适合边听边读 |
| **封面** | 让封面本身成为大幅画面 | 封面柔焦、纯高斯、封面舞台，保留不同的取景和柔化质感 |
| **内页** | 歌曲题头、封面与歌词形成稳定排版 | 像打开唱片内页，集中阅读一首歌 |
| **专注** | 把更多空间交给文字 | 安静背景、清楚的原译文层级，不依赖一张大封面 |

背景柔化、取景方式、背景缩放、前景封面的显隐／大小／位置、歌词对齐都可以按适用风格调整。数值支持滑块和精确输入；场景悬停预览可以开关，预览与正式采用分开，已有风格的设置会保留。

还可以使用封面配色、文字清晰度保护和可选的「夜间柔和」。按 **F** 进入专注模式时，工具栏、标题和播放控制收起，只留下歌词与背景；再次按 F 或 Esc 返回。

### 不只看原文，也看懂、跟得上

原文、译文、日语假名、罗马音与中文拼音可以按需要组合显示，并分别调整字号、对齐与辅助文字层级。

- **同步阅读**：跟随播放进度滚动，支持逐行同步；歌词含真实逐字时间时，可显示逐字高亮。点击带时间的歌词可以跳到对应位置。
- **日语注音**：汉字上方注音、独立假名行、假名替换或隐藏。普通读音生成使用本地引擎，不需要先配置 AI。
- **读音纠正**：可以手动修订读音；人工词典支持当前歌曲、当前歌手或所有歌曲的作用范围，适合人名、专有名词与特殊唱法。需要时可另行使用 AI 优化读音。
- **中文显示**：拼音支持声调符号、声调数字和无声调；繁简转换只改变显示，不改写保存的原词。
- **复制与修订**：复制单行、选定内容或整首歌词；对不上拍时先调整当前歌曲、当前版本的时间偏移，也可以进入编辑器逐行修订。

**译文和读音是独立的内容层。** 显示已有译文不等于发起 AI 翻译，生成读音也不等于把原词换成另一份歌词。

### 翻译成你愿意反复读的那一版

可以使用歌词来源自带的译文，也可以选择自己的翻译服务。译风提供自然歌曲、忠实直译、诗意流畅、上下文优先和自定义提示词；个人译风可以保存为档案，而不只是临时换一个模型。

已保存的译文可以直接复用；同一首歌可以保留多份翻译，并排比较后选择采用。重新翻译、手工修改和切换版本，不需要把原来喜欢的译文抹掉。自动翻译新歌词是独立选项，默认关闭。

| 接入方式 | 项目中的入口 | 使用前需要准备 |
| --- | --- | --- |
| **兼容 API** | OpenAI-compatible API、DeepSeek API | 对应服务的地址、API Key 和可用模型 |

日常翻译、重新翻译、已存版本与并排对比从「译文」入口操作；连接、凭据与个人译风在设置中管理。API 或 CLI 的额度与费用取决于所选服务，不随本应用提供。

### 先找可靠的歌词，再让它成为你的版本

应用会优先恢复本地已采用的歌词，也可以自动查找在线来源。结果足以确认当前歌曲时自动采用；存在同名异曲、编曲差异或身份不确定时，保留候选供你核对。人工编辑和锁定的版本不会被普通自动搜索覆盖。

搜索支持本地与在线结果、来源标识、预览和手动采用。**只有纯文本也可以阅读**：没有时间轴时会按未同步歌词呈现，不伪造逐行或逐字时间。

<details>
<summary><strong>歌词来源与搜索范围</strong></summary>

| 来源范围 | 内容 |
| --- | --- |
| **本地** | 用户歌词文件、已保存和已采用的版本、导入或手工创建的歌词 |
| **开放来源模式** | AMLL 社区排轴、LRCLIB、lyrics.ovh；其中 lyrics.ovh 是无时间轴的纯文本补充 |
| **扩展免费模式** | 在上述基础上增加网易云、QQ 音乐、酷狗、酷我实验源，以及 LinkCore 发行方公开歌词正文 |

可以在设置中选择来源模式、启用的来源及优先顺序。在线覆盖率、正文、译文和时间轴都依赖来源；找到歌曲目录不等于该来源一定提供歌词正文。扩展来源可能失效，也不意味着获得了内容再分发许可。

</details>

### 歌词库不只是缓存

原词、译文、读音、时间轴分别管理。你可以保留来源版本，在它的基础上修改，再决定用哪一份，而不是每次改错后重新找词。

| 操作 | 用途 |
| --- | --- |
| **预览、采用与切换** | 查看候选和已存版本，再决定当前歌曲使用哪一份 |
| **编辑与锁定** | 逐行修改原文、译文、读音和时间；支持插入、拆分、合并、撤销／重做，保存修订版本 |
| **导入与导出** | TXT／LRC、剪贴板内容、歌词与译文导出，以及个人歌词资产包 |
| **文件夹同步** | 使用自己指定的目录整理和交换歌词资产；是否进入云端取决于该目录的同步服务 |
| **最近播放与统计** | 查看应用运行期间观察到的播放记录、时长与歌曲／歌手排行，不冒充音乐平台的完整历史 |

### 完整主窗，也有轻一点的入口

| 显示方式 | 适合怎样使用 |
| --- | --- |
| **主窗口／原生全屏** | 完整封面、同步歌词、翻译与读音；常用工具按需展开 |
| **桌面歌词** | 单行或双行，可选择第二行内容；调整字号、透明度及各文字角色颜色，支持锁定、鼠标穿透与恢复交互 |
| **菜单栏歌词** | 不占主窗口空间；固定宽度或自适应最大宽度，长句可缓慢滚动或省略，点开查看歌词与播放控制 |
| **顶部胶囊** | 更紧凑的辅助显示入口，与主播放状态共用当前歌曲 |

普通播放栏之外，还可以把进度放到**窗口边缘**：进度线常驻，靠近边缘时再显示播放按钮，点击或拖动边缘跳转进度。颜色可选固定、自动流转、每首随机或跟随封面。

播放／暂停、上一首／下一首、随机播放和循环控制作用于当前播放器。心形按钮用于 Spotify「已点赞的歌曲」或 Apple Music「喜爱」；Spotify 的收藏操作需要另外连接账号，基础桌面播放同步与这项账号授权分开。

## 开始使用

1. **先播放一首歌。** 在 Spotify 桌面版或「音乐」App 中开始播放，再打开 Aster · Lyric。播放源可以自动检测，也可以在设置里指定；首次控制播放器时允许 macOS 的自动化授权。
2. **先确定歌词，再调整阅读。** 等待自动匹配；需要时从「搜索」预览并采用合适版本，或导入自己的 TXT／LRC。在「文字」选择原文、译文、假名／罗马音／拼音。
3. **按自己的听歌方式展开。** 在「画面」选择风格与播放呈现；需要新译文时配置翻译服务，再翻译当前歌曲。后台工作时可改用桌面或菜单栏歌词。

工具栏在鼠标进入窗口时出现，接近顶部时更清楚。悬停可临时查看工具面板，点击可固定需要的面板；画面与文字调整可以留在主窗外侧，不挤压正在观察的歌词构图。歌词库、搜索也提供完整窗口入口。

| 入口 | 内容 |
| --- | --- |

| **搜索** | 本地和在线歌曲／歌词结果，预览与采用 |
| **译文** | 翻译与读音操作、服务／模型选择、已存译文、整首翻译、重新翻译、自动翻译与对比 |
| **文字** | 内容层显隐、字号、对齐、清晰度、注音排版 |

| **更多** | 当前歌词时间偏移、桌面歌词、顶部胶囊、菜单栏歌词、全屏和桌面交互 |

## 下载与构建

### 已发布安装包

目前的公开发布包是 **[Spotify Lyrics v0.1.2](https://github.com/suifracti/aster-lyric/releases/tag/v0.1.2)**。它保留旧应用名，与当前 Aster · Lyric 开发版有功能和界面差异；不要用本页的新功能列表判断旧包是否安装成功。

现有安装包面向 **Apple Silicon（arm64）与 macOS 14+**，未提供 Intel 安装包。下载、源码浏览或构建均不改变仓库的 [许可范围](LICENSE)。

安装前建议导出重要歌词资产并保留旧版本。现有发布包没有 Developer ID 签名或 Apple 公证；遇到系统拦截时，确认下载来源后使用 macOS「隐私与安全性」中的单次打开许可，不要关闭系统安全保护。

### 当前开发版

在 macOS 上安装 Xcode 后，获取源码并打开工程：

```sh
git clone https://github.com/suifracti/aster-lyric.git
cd aster-lyric
open SpotifyLyrics.xcodeproj
```

选择 **SpotifyLyrics** scheme 构建。也可以通过命令行构建 Release 配置：

```sh
xcodebuild -project SpotifyLyrics.xcodeproj \
  -scheme SpotifyLyrics \
  -configuration Release \
  -derivedDataPath /tmp/aster-lyric-deriveddata \
  CODE_SIGNING_ALLOWED=NO build
```

该命令只构建，不会安装或覆盖现有 App。权限调试可能需要在 Xcode 中配置本机签名；不要提交个人证书、Team ID 或凭据。Release 是构建配置，不代表新的正式安装包已经发布。

工程名、Bundle ID `com.spotifylyrics.app` 和部分数据目录暂时保留旧名，是为了兼容已有歌词库、偏好与授权。**不要为了统一名称手动重命名或清理这些数据。**

## 常见问题

**为什么其他播放器有歌词，这里却没有？**  
不同应用使用的来源、授权与缓存不一定相同。Aster · Lyric 会区分服务暂不可用、来源只有目录而没有正文、候选身份尚未确认。可以重试健康来源、手动搜索或导入；查找失败不等于这首歌是纯音乐。

**为什么找到了歌词，却没有自动采用或跟随播放？**  
同名异曲、Piano Ver.、Live、Remix、加速版等需要区分录音身份。无法可靠确认的候选需要人工核对；可信纯文本可以使用，但没有时间轴就不会自动滚动。逐字高亮也必须有真实逐字时间数据。

**歌词总是快一点或慢一点，怎么调？**  
用 Z／C 或「更多」里的偏移调整整首固定误差。它只作用于当前歌曲、当前版本，不改变播放器进度或原始时间戳。若每行偏差不同，应换用更匹配的版本，或在编辑器修改逐行时间；一个偏移值不能修复不同编曲。

**显示译文或生成假名，会自动产生 AI 费用吗？**  
显示已保存的译文、普通本地读音生成不会触发 AI 翻译。新翻译、AI 读音优化及开启后的自动翻译会使用所选服务；所需登录、额度、费用与可用模型以该服务为准。机器翻译和自动读音仍可能需要人工校对。

**为什么运行后和截图不同？**  
先区分旧发布包、当前源码和实际启动的 App。更新源码不会自动替换已安装程序。截图只展示对应构建的一个状态，不代表所有歌曲、系统与窗口尺寸都已验证。

### 还在完善的部分

单句循环、大字模式、前奏／间奏倒计时、便捷的只读音／只译文模式、加入 Spotify 歌单、应用内侧边抽屉，以及边缘播放器进一步的跟随与点击手感优化，仍列为后续工作，**不计入上面的当前可用能力**。

在线词源不保证全曲库覆盖，AI 接入依赖用户实际配置，所有场景和辅助窗口的性能也仍接受真实使用反馈。遇到问题可提交 [Issue](https://github.com/suifracti/aster-lyric/issues)，附上应用版本或源码提交、macOS 版本、歌曲与播放器、歌词来源、重现步骤及必要截图；不要上传数据库、账号令牌或 API Key。

## 数据与隐私

| 数据或操作 | 保存与发送方式 |
| --- | --- |
| 歌词、采用版本、手工修订、听歌记录 | 默认保存在本机 Application Support 的歌词数据库中；偏好设置保存在本机 |
| 在线查词与封面 | 向对应来源发送查询所需的歌曲信息，并获取歌词、目录或封面资源 |
| 第三方 AI 翻译／读音优化 | 将处理所需的歌词、提示词及所选译风内容发送给你配置的服务 |
| App 管理的授权令牌与 API Key | 使用 macOS Keychain；本机 CLI 的登录状态由对应 CLI 管理 |
| Spotify 账号连接 | 用于查询、加入与移除「已点赞的歌曲」；与桌面播放同步分开，配置参考 [Spotify OAuth 说明](docs/SPOTIFY_OAUTH_SETUP.md) |
| 文件夹同步 | 使用你指定的位置；是否同步到云端由该文件夹所用的服务决定，不是应用另建的一套云端歌词库 |

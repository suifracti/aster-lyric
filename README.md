## 理念

听歌时极简，但不简陋。平时屏幕上只有歌词和画面；需要的时候，伸手就能找到想要的功能，用完它会安静退下。功能是收起来，不是删掉。

Aster · Lyric 是一款原生 macOS 歌词应用，只做两件事：**好好听歌，好好跟唱。**

## 现在能做什么

### 听歌

- **跟随播放**：跟随 Spotify 或 Apple Music 当前播放的歌曲和进度。切歌、暂停时，播放器一发出通知就立即更新，播放位置会定期校准。
- **播放控制**：播放 / 暂停、上一首、下一首、拖动进度；还有随机播放和循环（列表循环、单曲循环）。
- **喜欢**：心形按钮或 S 键，把当前歌曲加入 Spotify「喜欢」或 Apple Music「喜爱」，再操作一次就移除。Spotify 需要先在设置里连接账号。

### 画面

- **四类场景**：环境光、封面、内页、专注。每类下面有几种风格，包括经典版。
- **背景调节**：背景模糊、前景封面、背景动态、取景方式、背景缩放。
- **封面配色**：歌词高亮、进度条和控件的颜色取自当前封面。
- **清晰度**：关闭 / 文字阴影 / 柔和光晕，亮色封面上也能看清歌词。
- **夜间柔和**：晚上自动调暗画面、放缓背景动态。
- **专注模式**：只留歌词和背景。

### 歌词

- **自动找词**：自动从多个来源（AMLL、LRCLIB、LinkCore、lyrics.ovh，以及实验性的网易云、QQ 音乐、酷狗、酷我）挑合适的歌词并采用。每个版本都保留，随时可以切回；人工改过或锁定的版本不会被覆盖。
- **译文**：
  - AI 翻译，按你自己的中文表达习惯，可以选模型。也可以用苹果系统翻译。
  - 翻好的译文会保存下来，下次直接用，不重复生成。
  - 可以保存多份译文，并排对比，选一份使用。
- **读音**：
  - 假名、罗马音、拼音三种，可以注在汉字上方、单独成一行，或者直接替换原字。
  - 读错的字可以逐首纠正，也可以用 AI 优化不确定的读音。
- **歌词时间**：整首提前或延后，只对这首歌的当前版本生效，不改原始时间轴。
- **繁简转换**：简体、繁体互相转换。

### 工具栏

鼠标移到窗口里，工具栏才淡淡出现。悬停按钮会临时弹出面板，点击后面板固定在窗口外侧。

| 按钮 | 内容 |
| --- | --- |
| 歌词库 | 当前歌曲的各个版本，按原词、译文、读音、时间轴分组，点一下就切换 |
| 搜索 | 搜索歌曲和歌词：本地结果立即出现，在线结果随后补上 |
| 译文 | 翻译 / 读音、AI 模型、已保存的译文、翻译整首、重新翻译、自动翻译、并排对比 |
| 文字 | 显示原文 / 译文 / 读音、字号、对齐、清晰度、注音排版 |
| 画面 | 场景与风格、悬停预览、背景模糊与更多画面选项 |
| 更多 | 歌词时间、桌面歌词、顶部胶囊、菜单栏歌词、全屏、桌面歌词交互 |
| 设置 | 打开设置窗口 |

### 按键与手势

在主窗口里使用；正在输入框里打字时不生效。

| 键 | 作用 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| A、D | 上一首、下一首 |
| S | 加入「喜欢」；已经在里面时，再按一次移除 |
| Z、C | 歌词快了往前调、慢了往后调，每次 0.1 秒 |
| X | 歌词时间归零 |
| `,` `.` | 背景模糊 −5% / +5% |
| `/` | 背景模糊在 0 / 25 / 50 / 75 / 100% 之间循环 |
| ?（Shift + /） | 显示全部按键 |
| F | 专注模式 |

在触控板上双指捏合可以调字号，双指左右滑可以切换场景。

### 其他窗口

- **全屏歌词**
- **桌面歌词**：单行或双行；字号、配色预设，以及原文、已唱文字、读音、译文、描边的颜色；第二行显示什么也可以选。可以锁定，也可以设成鼠标穿透。
- **顶部胶囊**
- **菜单栏歌词**：宽度可以固定，也可以设最大宽度；长句会缓慢滚动。

### 管理

- **歌词库**：原词、译文、读音、时间轴分别管理版本。可以导入、导出 TXT / LRC 和个人歌词资产包，也可以同步到你指定的文件夹。
- **编辑器**：逐行编辑原文、译文、读音和时间，支持插入、拆分、合并、撤销，保存后成为新版本。
- **听歌记录**：最近播放和听歌统计。只记录应用运行期间看到的播放。

## 正在做

以下功能还在开发，**目前的版本里还没有**：

- 单句循环、大字模式、前奏和间奏倒计时、只看读音 / 只看译文
- 把歌曲加入 Spotify 歌单
- 侧边抽屉（在应用内打开歌词库和搜索）
- 边缘播放器的跟随动画，以及更容易点击的进度条

## 已知限制

- 歌词匹配不是百分之百准确：Piano Ver.、Live、Remix 这类版本可能匹配到原版或相近的录音。
- 调整歌词时间只能修正整首一致的偏差；每行误差不一样时，请换一个更匹配的版本，或者在编辑器里修改。
- 逐字高亮需要歌词来源提供真实的逐字时间。

## 下载与安装

- 正式发布版：**[v0.1.2](https://github.com/suifracti/aster-lyric/releases/tag/v0.1.2)**。这个版本较旧，应用名还是旧名 `SpotifyLyrics`，上面列出的很多功能它还没有。
- 仅支持 Apple Silicon（arm64），需要 macOS 14 或更高版本。
- 应用没有 Developer ID 签名，也没有经过 Apple 公证。系统阻止打开时，先确认下载来源，再到「隐私与安全性」里允许这一次打开。
- 第一次控制 Spotify 或 Apple Music 时，需要在系统弹窗里允许"自动化"权限。

## 从源码构建

```sh
git clone https://github.com/suifracti/aster-lyric.git
cd aster-lyric
open SpotifyLyrics.xcodeproj
```

也可以用命令行构建 Debug 版本：

```sh
xcodebuild -project SpotifyLyrics.xcodeproj \
  -scheme SpotifyLyrics \
  -configuration Debug \
  -derivedDataPath /tmp/aster-lyric-deriveddata \
  CODE_SIGNING_ALLOWED=NO build
```

需要 macOS 和 Xcode。不要提交个人证书、Team ID 或任何凭据。

## 数据与隐私

- 歌词、修订版本和听歌记录保存在本机的 Application Support 数据库里，偏好设置也只保存在本机。
- 登录令牌和 API Key 保存在钥匙串里。
- 查询在线歌词时，会把匹配所需的歌曲信息发给对应的歌词来源。
- 使用 AI 翻译时，会把歌词文本发给你选择的 AI 服务。
- 连接 Spotify 后，只读取和修改你的「喜欢」列表。
- 同步到文件夹时，只写入你指定的位置；会不会上传到云端，取决于那个文件夹用的同步服务。
